# Security policy

Please do not report vulnerabilities involving credentials, private notebook
content, package signing, or handwritten.blog account access in a public issue.
Email `hello@handwritten.blog` with a concise description and reproduction
steps.

The uploader never needs a reMarkable Cloud credential. If any installation or
website asks for one, stop and report it.

Supported versions and firmware combinations will be listed in the README and
Vellum package constraints. Development builds outside that matrix are not
supported.
